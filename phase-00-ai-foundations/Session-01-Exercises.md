# Session 01 — Exercises

## 1. What is the difference between AI, ML, and DL?

**Artificial Intelligence (AI)** is a general concept that refers to systems that can perform intelligent tasks. These systems can perform tasks that usually require human intelligence.

**Machine Learning (ML)** is one of the most important approaches in AI. Instead of programming all decision-making rules manually, we build a model that learns patterns from data and uses them to make predictions or decisions.

**Deep Learning (DL)** is a subfield of ML that is based on multi-layer neural networks. It is especially useful for learning complex patterns from large amounts of data.

---

## 2. What is the difference between Generative AI and Classification?

**Generative AI** is a field of AI that focuses on generating new content based on learned patterns. For example, it can generate text, images, audio, video, or code.

**Classification** is a machine learning task in which a model assigns an input to one of several predefined classes.

For example:

- An image → **Cat**
- An image → **Dog**
- An email → **Spam**
- An email → **Not Spam**

## 3. Give three applications of Computer Vision.

### Self-driving cars

Computer Vision helps self-driving cars understand their environment by detecting pedestrians, animals, other vehicles, road signs, and other objects that can affect driving.

### Surveillance cameras

Computer Vision can be used to detect people and objects and identify certain activities or unusual behaviors.

### Robots

Computer Vision helps robots understand their surrounding environment and detect and recognize different objects.

## 4. Give an example of an AI Agent.

For example, we can ask an AI Agent to write a Python program that performs operations A, B, and C.

The Agent can then:

1. Write the code.
2. Run the code.
3. Test it several times.
4. Detect errors or problems.
5. Modify the code.
6. Run the tests again.
7. Evaluate the results.
8. Continue improving the solution until it reaches the desired result.

This is different from simply asking an AI to write code once and give us the final answer.

---

## 5. Why should we learn Neural Networks if AI can write them for us?

Because engineering and designing a system requires more than just the ability to write code.

A person needs enough knowledge to understand how the system works, design it correctly, evaluate its performance, and diagnose and fix problems when they occur.

AI can help us write code, but we should be able to understand, evaluate, and modify that code ourselves.

**Artificial Intelligence (AI)**

**Machine Learning (ML)**

- ML is a subset of AI.

- DL is a subset of ML.
- It uses multi-layer neural networks.

**AI ⊃ ML ⊃ DL**

This means that every DL system is an ML system, and every ML system is an AI system, but the opposite is not necessarily true.
