# Daily Task Tracker

A simple command-line application built with Python to manage daily tasks and track task completion.

This mini-project was developed as a practical review of Python fundamentals covered in Sessions 1–20 of my AI & Deep Learning learning journey.

## Features

- **Dashboard:** View total, completed, and pending tasks, along with the completion percentage.
- **Show Today's Tasks:** Display all tasks with their IDs, titles, and statuses.
- **Add Task:** Create a task with a unique ID and a non-empty title.
- **Complete Task:** Mark a task as completed using its ID.
- **Input Validation:** Handle empty task titles, invalid IDs, and tasks that have already been completed.
- **Interactive Menu:** Navigate the application through a simple terminal menu.

## Technologies

- Python 3
- Python standard library only

No external packages are required.

## Getting Started

### Prerequisites

Install Python 3 on your computer.

### Run the Application

1. Clone this repository or download the project files.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python main.py
```

If your system uses the Python launcher, you can also run:

```bash
py main.py
```

## Current Limitations

- Tasks are stored in memory and are lost when the application closes.
- The application runs in the terminal and has no graphical user interface.
- Tasks cannot currently be edited or deleted.
