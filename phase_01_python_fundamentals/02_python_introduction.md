# Session 02 — Python Introduction

## 1. What is Python?

Python is a high-level, general-purpose programming language.

It is one of the most widely used programming languages in Artificial Intelligence, Machine Learning, Data Science, and many other fields.

Python is popular partly because its syntax is relatively simple and readable, which makes it easier to learn and use.

---

## 2. Why is Python Important for AI?

Python is one of the main programming languages used in AI because it has a powerful ecosystem of libraries and frameworks.

Some important examples are:

- NumPy — Numerical computing
- Pandas — Data analysis and manipulation
- Scikit-learn — Machine Learning
- PyTorch — Deep Learning
- TensorFlow — Deep Learning
- OpenCV — Computer Vision

Python also has a large community and many learning resources.

---

## 3. Python is Not AI

Python itself is not Artificial Intelligence.

Python is a programming language that can be used to build AI systems.

The relationship can be simplified as:

Python → AI Programs → Machine Learning → Deep Learning → Computer Vision

---

## 4. Python vs PyTorch

Python and PyTorch are not the same type of technology.

### Python

Python is a:

**Programming Language**

### PyTorch

PyTorch is a:

**Machine Learning / Deep Learning Framework**

PyTorch is mainly used to build, train, and run machine learning and deep learning models.

Therefore:

**Python = Programming Language**

**PyTorch = Deep Learning Framework**

---

## 5. Is Python the Only Language Used in AI?

No.

Other programming languages such as C++, Java, and Julia can also be used in AI.

However, Python is especially popular because of:

- Powerful AI ecosystem
- Large number of libraries and frameworks
- Large community
- Many educational resources
- Fast development and experimentation

## 8. Python for AI Engineering

Learning Python for AI is not only about memorizing syntax.

The goal is to learn how to:

- Understand code
- Write code
- Read code
- Debug code
- Use libraries
- Build AI systems
- Evaluate AI-generated code
- Understand what the code is doing

AI tools can help write code, but an AI engineer must still understand and evaluate that code.

- Python is widely used in AI and Machine Learning.
- Python is not AI itself.
- Python has a powerful ecosystem for AI.
- PyTorch is a Deep Learning framework, not a programming language.
- Python is not the only language used in AI.
